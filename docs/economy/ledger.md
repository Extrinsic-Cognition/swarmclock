# The swarmclock economy: build ledger

Companion to `docs/poleis-swarmclock-economy-prd.md`. The PRD says what the
rail will be; this ledger says what stands, with the numbers, in the order it
was built. English, no em dashes, numbers with their provenance.

## 1. Hop 1, the book (2026-09-07, before dawn)

alice: "do all." The book was built as one organ with two consumers.

- `antimirror-app/tools/swarmclock_book.py`: open, append (retro or
  envelope through the admit gate `chat_crypto.py`, with an optional roster
  file), close (sha256 Merkle root over exact line bytes, header included,
  odd nodes promoted; root file written atomically; book sealed read-only),
  prove, verify, root. Standard library only. Eight tests green: every
  index proves at sizes 1 to 33, one altered byte fails, order changes the
  root, a foreign proof is refused, an empty book has a value, the CLI
  round trip, a sealed book refuses appends, the gate refuses blind.
- `ec-workspace/tools/swarmclock-book/book.mjs`: the same algorithm in Node
  with zero dependencies, for the MCCR place file and the Poleis pages:
  root, prove, verify over any newline-JSON file. Six tests green. The
  shared vector `vector.json` (nine lines, one with non-ASCII bytes, root
  `b9bdc7f2…`) is generated by Python and must reproduce in Node.
- One organ, checked on real data, not only on the vector: Node recomputes
  the root of the Python-closed book below and gets the same value; Node
  verifies a Python proof and Python verifies a Node proof of the same
  book. The MCCR fixture `prototypes/mccr/fixtures/north-wall.jsonl` roots
  as a book of 22 lines (`36754ab3…`) with no change to the file.
